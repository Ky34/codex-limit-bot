# Инструкции проекта Codex Limit Bot

- Перед работой прочитай `README.md` и проверь `git status --short --branch` и удалённую ветку. GitHub хранит версионируемый код этого проекта.
- `main` содержит актуальную основную версию бота. Изменения сначала разрабатывай и тестируй в отдельной ветке; переноси их в `main` только после успешных тестов и явного разрешения пользователя. Не объединяй ветки ради синхронизации устройств.
- Бот работает на VPS. Отправка изменений в GitHub сама по себе не обновляет сервер. Перед конкретным обновлением рабочего бота требуется разрешение пользователя; сохрани прежнюю версию на сервере и проверь службы после установки.
- Не запускай локальный Telegram listener с рабочим токеном одновременно с серверным listener: оба процесса будут забирать команды из одного чата.
- Не добавляй в Git токены, сессии Codex, файлы `.env`, `auth.json`, `state.json`, `updates.json` или каталог `.codex`. Доступ к секретам на другом устройстве организуй через Bitwarden.
- После изменений в коде запусти `python3 -m unittest discover -s tests -v` (в Windows также подойдёт `python`). Перед сменой устройства проверь чистоту рабочей копии и отправку нужных коммитов в GitHub.
