# Codex Limit Bot

Telegram-бот [@Ky3aLimitsbot](https://t.me/Ky3aLimitsbot) отслеживает пятичасовой и недельный лимиты Codex через Codex App Server. Проверяет остатки каждую минуту, предупреждает об исчерпании и показывает время следующего обновления.

## Возможности

- Уведомляет при остатке 20%, 10%, 5% и при достижении 0%; не дублирует сообщение об исчерпании из-за изменения расчётного времени сброса.
- Сообщает о сбросе каждого лимита и о временной недоступности данных с последующим восстановлением.
- Показывает оба лимита по команде `/limits` или кнопке «📊 Лимиты». Время обновления отображается по часовому поясу устройства Telegram; предусмотрено резервное время Минска.
- С 02:00 до 10:00 по сохранённому часовому поясу отправляет автоматические сообщения без звука. Ответы на запросы приходят обычно.

## Как пользоваться

Откройте бота в привязанном личном чате и отправьте `/start`, чтобы показать клавиатуру. Нажмите «📊 Лимиты» для текущего состояния. После смены часового пояса нажмите «📍 Обновить часовой пояс»: Telegram однократно отправит геопозицию. Если клавиатура скрыта, отправьте `/timezone`. Живая трансляция не требуется.

## Ограничения и особенности

- Бот зависит от доступности данных Codex App Server и принимает команды только из настроенного личного чата.
- Лимиты отслеживаются независимо: сообщение о сбросе одного из них может прийти, когда другой остаётся на 0%. Это **не означает восстановления доступа**. Изменение такого поведения запланировано, но ещё не реализовано.
- Геопозиция используется для определения часового пояса; координаты в файл состояния не записываются.

## Размещение и версии

Активный бот размещён на собственном VPS пользователя; рабочая точка доступа для обслуживания — `ssh my-vps`. Проверку лимитов запускает `codex-limit-bot.timer`, команды Telegram обрабатывает `codex-limit-bot-listener.service`. Подтверждённые компоненты прежнего экземпляра удалены со старого VPS. Секреты и рабочие файлы состояния не входят в репозиторий.

Согласованная и развёрнутая версия — **[v1.1.1](https://github.com/Ky34/codex-limit-bot/releases/tag/v1.1.1)**. Следующий этап — автоматический деплой того же проверенного commit после разрешённой публикации в `main`; до этого ручное развёртывание выполняется отдельно после согласования. История — в [CHANGELOG.md](CHANGELOG.md), текущий номер — в [VERSION](VERSION). Локальное размещение проекта описано в [LOCAL-LAYOUT.md](LOCAL-LAYOUT.md).
