# Состояние проекта codex-limit-bot

## Назначение

Telegram-бот сообщает о пятичасовом и недельном лимитах Codex, порогах остатка, сбросах и временной недоступности данных. Также поддерживаются запрос текущих лимитов и определение часового пояса пользователя.

## Ветки и устройства

- Основная ветка: `main`.
- Рабочая ветка: `dev`.
- Устройства разработки: `windows-pc`, `macbook`.
- Обычная межустройственная синхронизация выполняется через `dev`.
- Публикация в `main` требует отдельного конкретного разрешения пользователя.

## Текущее состояние

- Актуальная версия функций бота объединена в `main`; рабочая `dev` создана от этой версии.
- Бот проверяет лимиты раз в минуту, уведомляет о порогах 20%, 10%, 5% и 0%, сообщает о сбросе и поддерживает команду `/limits`.
- Поддерживаются тихие часы и часовой пояс, определяемый по разово переданной геопозиции.
- Рабочий экземпляр размещён на VPS. GitHub и локальные копии не являются его автоматическим развёртыванием.

## Устройство проекта

- Основная логика находится в `bot.py`.
- Шаблоны служб и таймера находятся в репозитории и используются при отдельно согласованном обновлении VPS.
- Автоматические проверки находятся в `tests/`.
- Секреты, авторизация Codex и рабочие файлы состояния VPS в Git не входят.

## Проверки

- Перед созданием `dev` актуальная версия уже была объединена в `main` коммитом `86d4a2f`.
- В рамках настройки синхронизации меняется только документация, поэтому тесты кода повторно не запускались.
- На Windows проверены наличие командных правил, файла состояния и корректность изменённой документации.
- При отправке `dev` проверяются совпадение локальной и удалённой вершины и чистота рабочей копии.
- Реальный двусторонний цикл через MacBook пока не выполнен.

## Следующий шаг

Получить `dev` на MacBook, прочитать этот файл, выполнить безопасное тестовое изменение документации и вернуть его через `dev` на Windows. Публикацию в `main` и обновление VPS рассматривать как отдельные действия.

## Ограничения и риски

- Отправка коммитов в GitHub не обновляет работающего бота.
- Нельзя запускать локальный Telegram listener с рабочим токеном одновременно с серверным listener.
- Нельзя помещать в Git токены, файлы авторизации, локальные состояния или содержимое `.codex`.
- Нельзя обновлять или останавливать рабочий бот на VPS без отдельного разрешения.
