# Уведомления о лимитах Codex

Программа проверяет пятичасовой и недельный лимиты через официальный Codex App Server. При остатке 20%, 10% и 5% она отправляет предупреждение с фактическим остатком и временем обновления обоих лимитов. При пересечении сразу нескольких порогов отправляется одно сообщение. После сброса пятичасового или недельного лимита приходит отдельное уведомление 🔄. Предупреждения, уведомления о сбросе и ответы на запрос имеют общий формат: заголовок, два блока ⏱️/📅 и разделительную строку. Названия лимитов и проценты выделены жирным шрифтом через Telegram HTML; время обновления Telegram отображает в часовом поясе устройства. Для старых клиентов резервный текст даты записан словами по времени Минска. Уже отправленные уведомления учитываются в `/var/lib/codex-limit-bot/state.json`; при обновлении старые уровни 30/20/10% автоматически преобразуются в новые.

На VPS программа размещена в `/opt/codex-limit-bot`, запускается отдельным пользователем `codexbot`. Таймер `codex-limit-bot.timer` проверяет лимиты раз в минуту. Сервис `codex-limit-bot-listener.service` принимает команды Telegram. Секреты не входят в репозиторий: вход Codex хранится в закрытом каталоге пользователя `codexbot`, токен Telegram и chat ID — в `/etc/codex-limit-bot.env` с правами `0600`.

Бот [@Ky3aLimitsbot](https://t.me/Ky3aLimitsbot) подключён к личному чату. Временная команда `/limits` запрашивает текущие остатки и время обновления обоих лимитов в таком же формате. Команду можно заменить через `TELEGRAM_STATUS_COMMAND` в `/etc/codex-limit-bot.env` без изменения кода. Бот отвечает только в настроенном чате. Для проверки состояния: `systemctl status codex-limit-bot.timer codex-limit-bot-listener.service`. Для разовой проверки: `systemctl start codex-limit-bot.service`.

С 02:00 до 10:00 по местному времени все автоматические сообщения (пороги, сбросы, ошибки и восстановление) отправляются в Telegram без звука. По умолчанию используется часовой пояс Минска. Чтобы бот автоматически менял тихие часы в поездках, отправь ему живую геолокацию через Telegram (скрепка → Геопозиция → Транслировать геопозицию). Бот подтвердит выбранный часовой пояс и затем обновит его при перемещении. При завершении трансляции останется последний известный часовой пояс; для дальнейшей автоматической смены трансляцию нужно включить снова. Если отправить обычную точку, бот установит её часовой пояс однократно. Координаты используются только для определения часового пояса и не записываются на диск; файл `/var/lib/codex-limit-bot/timezone.json` хранит название зоны и состояние трансляции. Проверки продолжаются, сообщения не откладываются. Ответ на `/limits` приходит обычным способом в любое время.

При потере доступа к лимитам бот отправляет одно предупреждение и сообщение о восстановлении после следующей успешной проверки.

Локальная проверка в виртуальном окружении: `python -m unittest discover -s tests -v`.

## Работа с Windows и macOS

GitHub хранит исходный код проекта. Ветка `main` оставлена как первоначальная версия; действующая версия бота находится в `codex/limit-alerts-v2`. При обычном клонировании GitHub откроет `main`, поэтому на новом MacBook переключись на действующую ветку:

```sh
git clone https://github.com/Ky34/codex-limit-bot.git
cd codex-limit-bot
git switch --track origin/codex/limit-alerts-v2
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

Для разработки нужен Python 3.11 или новее. Установи зависимости из `requirements.txt` в виртуальное окружение и затем запусти тесты. Перед работой на каждом устройстве проверь `git status --short --branch` и получи изменения командой `git pull --ff-only` в действующей ветке. После работы сохрани изменения коммитом и отправь ветку командой `git push`. На втором устройстве снова выполни `git pull --ff-only`. Если есть локальные несохранённые изменения или конфликт, сначала разберись с ними; не перезаписывай файлы принудительно.

GitHub не синхронизирует локальные чаты, секреты и рабочее состояние бота на VPS. Токен Telegram и вход Codex не копируются в репозиторий; доступ к ним с другого устройства организуется через Bitwarden. Отправка коммита в GitHub не обновляет работающий сервер: установку изменений на VPS выполняют отдельно после согласования и проверки.
