# История версий Codex Limit Bot

Версии согласованы ретроспективно по истории Git 22.09.2026. Это логические этапы развития проекта: первоначальные коммиты не переписывались, а номера до введения SemVer не были фактически выпущенными GitHub Releases. Даты ниже — даты контрольных коммитов по UTC. Версию запущенного экземпляра VPS необходимо проверять отдельно: публикация в GitHub не выполняет развёртывание.

## 1.1.1 — 21.09.2026

**PATCH:** устранены повторные уведомления о 0% при изменении расчётного времени сброса лимита. Уведомление о фактическом исчерпании отправляется один раз.

Контрольный коммит: [e6a1795](https://github.com/Ky34/codex-limit-bot/commit/e6a1795d8909913adc1e9b38e1a81f1cbffcaf2a). Код затем объединён в `main` коммитом [86d4a2f](https://github.com/Ky34/codex-limit-bot/commit/86d4a2f550c9ded56b9a64fab21d170cc1396f9c).

## 1.1.0 — 20.09.2026

**MINOR:** добавлена кнопка «📊 Лимиты» для запроса текущего состояния без ввода команды `/limits`.

Контрольный коммит: [1eca48e](https://github.com/Ky34/codex-limit-bot/commit/1eca48ef587ea0ed2d7d19b115712d0138fc9ae5).

## 1.0.0 — 20.09.2026

**Первый стабильный релиз по решению пользователя.** Реализовано разовое обновление часового пояса через кнопку; постоянная передача геопозиции больше не требуется. Бот на этой стадии принят для постоянного использования.

Контрольный коммит: [00f9a5e](https://github.com/Ky34/codex-limit-bot/commit/00f9a5ea698d98652d29a20575ce4913b002b01e).

## 0.6.0 — 20.09.2026

Определение местного часового пояса по геопозиции для тихих часов. На этом этапе использовалась живая геолокация.

Контрольный коммит: [71bed36](https://github.com/Ky34/codex-limit-bot/commit/71bed36640d476227c2a48c9ab1ee9ceaf84c4c5).

## 0.5.0 — 20.09.2026

Время сброса адаптировано для локального отображения Telegram; добавлено резервное время Минска.

Контрольный коммит: [abbdbb0](https://github.com/Ky34/codex-limit-bot/commit/abbdbb0201bfb58e68ab7eb78b9c0d695b8f85c6).

## 0.4.0 — 20.09.2026

Тихие часы с 02:00 до 10:00: автоматические уведомления без звука, ответы на прямые запросы — обычные.

Контрольный коммит: [97f9942](https://github.com/Ky34/codex-limit-bot/commit/97f99423e29a19c977633b26bc886b2cf79ee1da).

## 0.3.0 — 20.09.2026

Интервал проверки лимитов сокращён с десяти минут до одной. Обновлены таймер и сообщение при отсутствии данных.

Контрольный коммит: [9fe87a5](https://github.com/Ky34/codex-limit-bot/commit/9fe87a584c81221ddb2c11203bd25ad90384fbc2).

## 0.2.1 — 19.09.2026

Исправлен и унифицирован формат сообщений: текст, значки, выделение, время сброса, оформление предупреждений и ответа на запрос. В одну версию сгруппированы последовательные косметические изменения.

Контрольный коммит: [5cd3d6e](https://github.com/Ky34/codex-limit-bot/commit/5cd3d6e5a90d5f5d83941791519dbaefed467348).

## 0.2.0 — 19.09.2026

Расширенные пороги 20%, 10%, 5%, уведомления о сбросах, команда `/limits`, служба обработки команд Telegram и первые автоматические тесты.

Контрольный коммит: [1cdbb22](https://github.com/Ky34/codex-limit-bot/commit/1cdbb226083c858b7e404e23079903d972416b60).

## 0.1.0 — 19.09.2026

Первый бот: пятичасовой и недельный лимиты Codex, пороги 30%, 20%, 10%, проверка раз в десять минут, шаблоны запуска на VPS.

Контрольный коммит: [8bf61c1](https://github.com/Ky34/codex-limit-bot/commit/8bf61c1cb7c4c0d2b5c3e264457e05791edbbe3b).
