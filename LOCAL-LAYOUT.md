# Локальное размещение проекта

Основная рабочая папка Windows: `C:\Users\User\Documents\Codex\Projects\codex-limit-bot`.

Здесь находятся репозиторий Git со всей историей, код бота, тесты, шаблоны служб и таймера, документация и локальное окружение `.venv`. Для запуска и тестов на Windows используйте путь к новому каталогу и `python -m pip` из `.venv` при обслуживании зависимостей. 18 локальных тестов `unittest` прошли после переноса.

Прежний адрес `C:\Users\User\Documents\ChatGPT\подготовка` временно сохранён для существующего чата: Windows удерживает каталог открытым, его содержимое теперь ведёт к рабочим файлам через ссылки. Основным местом разработки является новый каталог. После закрытия удерживающего процесса старый адрес можно убрать только после отдельной проверки.

Рабочая служба и её данные на VPS остаются на сервере; локальные файлы `*.service` и `*.timer` в этом репозитории являются шаблонами, а не установленной службой. Секреты и локальная история Codex не хранятся в репозитории. Глобальные инструкции находятся в `C:\Users\User\.codex\AGENTS.md`, а их исходник — в отдельном проекте `codex-workspace`.
