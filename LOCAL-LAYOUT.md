# Локальное размещение проекта

Основная рабочая папка Windows: `C:\Users\User\Documents\Codex\Projects\codex-limit-bot`.

Здесь находятся репозиторий Git со всей историей, код бота, тесты, шаблоны служб и таймера, документация и локальное окружение `.venv`. Для запуска и тестов на Windows используйте путь к новому каталогу и `python -m pip` из `.venv` при обслуживании зависимостей. 18 локальных тестов `unittest` прошли после переноса.

Содержимое прежнего адреса `C:\Users\User\Documents\ChatGPT\подготовка` и созданные для совместимости ссылки удалены 21 сентября 2026 года после проверки Git, тестов и отсутствия действующих зависимостей. Пустой каталог может оставаться до закрытия старого чата, который удерживает его открытым. Все локальные переносимые файлы проекта находятся в основной рабочей папке. Для дальнейшей работы используется локальный проект Codex, привязанный к новой папке.

Активная рабочая служба и её данные находятся на собственном VPS пользователя; для обслуживания используется `ssh my-vps`. Проект на сервере расположен в `/opt/codex-limit-bot`, рабочее состояние — в `/var/lib/codex-limit-bot`; локальные файлы `*.service` и `*.timer` в этом репозитории являются шаблонами. Подтверждённые компоненты прежнего экземпляра удалены со старого VPS без изменения чужих служб. Секреты и локальная история Codex не хранятся в репозитории. Глобальные инструкции находятся в `C:\Users\User\.codex\AGENTS.md`, а их исходник — в отдельном проекте `codex-workspace`.
